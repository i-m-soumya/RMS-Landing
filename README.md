# RMS Landing

A marketing landing page for the RMS platform, built with Astro and React.

## Tech Stack

- Astro
- React
- Vite
- Tailwind CSS

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open the local site in your browser.

## Available Scripts

```bash
npm run dev     # start local development server
npm run build   # build the production site
npm run preview # preview the production build
```

## Project Structure

```text
.

```

## Deployment

This project is ready to be deployed to a static hosting platform or a Node-compatible hosting environment that supports Astro builds.
